Step 1: Create a DynamoDB Table
1. Open the AWS Management Console.
2. Search for DynamoDB.
3. Select Tables → Create table.
4. Enter the following details:
   - Table name: DateTimeTable
   - Partition key: id
   - Key type: String
5. Click Create table.
Step 2: Create an IAM Role
1. Search for IAM in the AWS Console.
2. Select Roles → Create role.
3. Choose AWS service → Lambda.
4. Attach the AmazonDynamoDBFullAccess policy for this classroom practical.
5. Enter the role name LambdaDynamoDBRole.
6. Create the role.
Note: For production, use a custom policy that allows only the required DynamoDB write operation on this specific table.
Step 3: Create a Lambda Function
1. Search for Lambda in the AWS Console.
2. Click Create function.
3. Select Author from scratch.
4. Enter:
   - Function name: StoreDateTime
   - Runtime: Python 3.x
5. Create the function.
6. Open Configuration → Permissions → Execution role and assign the LambdaDynamoDBRole you created.
Step 4: Write the Lambda Code
Replace the default code in lambda_function.py with the following:
import boto3
from datetime import datetime, timezone
import uuid

dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('DateTimeTable')

def lambda_handler(event, context):
    current_time = datetime.now(timezone.utc).isoformat()

    table.put_item(
        Item={
            'id': str(uuid.uuid4()),
            'date_time': current_time
        }
    )

    return {
        'statusCode': 200,
        'body': 'Date and time stored successfully: ' + current_time
    }



How it works:
- Gets the current date and time in UTC.
- Generates a unique ID for each execution.
- Stores the ID and date/time in DynamoDB.
- Returns a success message.
Click Deploy to save the code.
Step 5: Test the Function
1. Click Test in the Lambda console.
2. Create a test event named TestDateTime.
3. Use the following JSON:
{}

4. Click Save, then Test.
You should see a successful execution response containing the date and time.
Step 6: Verify in DynamoDB
1. Open DynamoDB.
2. Select DateTimeTable.
3. Click Explore table items.
4. You should see a new item containing:
   - id
   - date_time
Run the Lambda function again to insert another record.
